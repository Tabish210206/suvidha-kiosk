# SUVIDHA 4.0 - Accessibility Features Guide

## Overview

SUVIDHA 4.0 is designed with comprehensive accessibility features to serve citizens with diverse needs:
- **Visually Impaired Users** (Blind/Low Vision)
- **Senior Citizens**
- **Persons with Motor Disabilities**
- **Hearing Impaired Users**
- **Persons with Cognitive Disabilities**

---

## Accessibility Modes

### 1. **Standard Mode** 📱
- **Target Users:** General public
- **Features:**
  - WCAG 2.1 Level AA compliant
  - Standard font size (16px)
  - 4.5:1 color contrast ratio
  - Normal animation speeds
  - Keyboard navigation support

---

### 2. **Visually Impaired Mode (Demo)** 🎧
**Currently Active for Demo**

- **Target Users:** Blind and visually impaired users
- **Features:**
  - Full voice-based navigation
  - Screen reader optimized
  - Audio descriptions for all UI elements
  - Auto-announcement of page content
  - Voice command support
  - High contrast UI elements
  - Large touch targets (64x64px minimum)
  - Text-to-speech for all content

**How to Use:**
1. The system automatically speaks page titles and descriptions
2. Use the "Repeat" button in the voice guide overlay (bottom-right) to hear the content again
3. All buttons and interactive elements announce their purpose when focused
4. Navigation is possible using keyboard arrow keys and Enter

**Voice Features:**
- Announcements in multiple languages (English, Hindi, Tamil, Telugu, Kannada)
- Adjustable speech rate
- Voice confirmation for actions

---

### 3. **Hearing Impaired Mode (Demo)** 👁️
- **Target Users:** Deaf and hard of hearing users
- **Features:**
  - Visual captions for all audio content
  - No reliance on sound
  - Maximum visual contrast (7:1)
  - Large, clear text
  - Visual indicators for alerts and notifications
  - Sign language video support (optional)
  - Text-based communication

---

### 4. **Motor Disability Mode (Demo)** 🎤
- **Target Users:** Users with motor disabilities or limited mobility
- **Features:**
  - Voice control enabled
  - Minimal clicking required
  - Large touch targets (80x80px minimum)
  - Keyboard navigation support
  - Slow animation speeds
  - Simple navigation paths
  - On-screen keyboard for text input
  - Reduced precision requirements

**Voice Commands:**
- "Next" - Move to next element
- "Previous" - Move to previous element
- "Select" / "Activate" - Click current element
- "Menu" - Open navigation
- "Help" - Get assistance

## Key Accessibility Features

### Visual Design
- **Color Blind Safe:** Palette verified for color blindness
- **High Contrast:** Available in multiple contrast levels
- **Large Fonts:** Scalable from 16px to 32px+
- **Clear Typography:** Sans-serif fonts for readability

### Navigation
- **Keyboard Navigation:** Full keyboard support
- **Screen Reader Support:** ARIA labels and landmarks
- **Focus Indicators:** Clear visual focus outlines
- **Skip Links:** Jump to main content

### Input Methods
- **On-Screen Keyboard:** For kiosk environments
- **Voice Input:** Supported in Motor and Blind modes
- **Touch Optimization:** Large buttons with padding
- **Mouse & Keyboard:** Both fully supported

### Language Support

- हिंदी (Hindi)
- தமிழ் (Tamil)
- తెలుగు (Telugu)

## Accessing Accessibility Mode Selector

### Location
After language selection, look for the **accessibility mode icon** in the **top-right corner** of the screen.

### How to Switch Modes
1. Click the accessibility mode button (top-right)
2. Select your preferred mode from the dropdown menu
3. The system will announce the mode change
4. The interface will adjust immediately

## Tips for Users

### For Visually Impaired Users
- Use a screen reader (NVDA, JAWS, VoiceOver)
- Enable voice mode for automatic announcements
- Use keyboard shortcuts for faster navigation
- Request large print receipts

### For Senior Citizens
- Ask staff to help switch to Senior Citizen Mode
- Increase text size in settings
- Enable voice assistance
- Use the simple navigation layout

### For Motor Disability
- Use voice commands instead of clicking
- Use keyboard navigation (Tab, Arrow Keys, Enter)
- Request staff assistance with physical input
- Use accessible peripherals

### For Hearing Impaired
- Enable captions for all audio
- Use text chat with support staff
- Request written confirmations
- Visual alerts are enabled by default
